# 🍬 while(GULOSO)

> Jogo desenvolvido em **C++** com a biblioteca **[Raylib]** para a disciplina de Linguagem de Programação 1 (LP1) por estudantes da Universidade do Estado da Bahia.

## 🛠️ Tecnologias e Dependências

- **Linguagem:** C++17
- **Biblioteca Gráfica & Áudio:** [Raylib](https://www.raylib.com/)
- **Compilação:** GNU Make (`make`) & `g++`

---

## Como Executar

### 1. Instalar as dependências

#### No Ubuntu / Debian / Linux Mint:
```bash
sudo apt update
sudo apt install -y build-essential libraylib-dev
```

#### No Arch Linux:
```bash
sudo pacman -S base-devel raylib
```

#### No Fedora:
```bash
sudo dnf install @development-tools raylib-devel
```

---

### 2. Clonar o repositório

```bash
git clone https://github.com/camilessaraiva/while-GULOSO.git
cd while-GULOSO
```

---

### 3. Compilar e Jogar

Para compilar e iniciar o jogo em um único comando:
```bash
make run
```

Ou, se preferir compilar e rodar manualmente:
```bash
make
./build/while_guloso
```

Para limpar os arquivos de build gerados:
```bash
make clean
```
